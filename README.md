# LANGUAGE DRIFT

日本語を起点に、3地域・500年間の言語分岐を観察するブラウザゲームです。v4は発音の経済性と識別性の競合から、短縮・補償的長文化・文法化・再縮約が循環するモデルです。従来の5種類の内的圧力と世代・接触シミュレーションに接続しています。

## 遊び方

`index.html` をブラウザで開くだけで動きます。インストール・通信・外部APIは不要です。任意で `npm start` を実行し、http://127.0.0.1:4173 で起動できます。

時間を進め、地域を選択して10年ごとに政策を実施します。「縮む、補う、また変わる。」では地域を選び、平均語長・文長等の推移と文法化サイクルを確認できます。推移項目と観測年のスライダーで過去を比較できます。「一文でたどる」では現在・過去・未来・否定・完了の例文を切り替え、「ひとつの語の、生涯」で基本語と新語の発音・意味・活用・補償理由・履歴を確認できます。語彙表の語形をクリックしても履歴を選べます。「文法と音変化」で初期と現在の体系、世代別の新形使用率、借用・構文の使用例を確認できます。

「介入なしと比較」は同じシード・同じ年数の基準世界を並行計算します。「実験記録を保存」でモデルバージョン・シード・介入履歴・地域間接続・イベント・世代別体系スナップショット・最終状態をJSON保存します。同じバージョン、シード、介入年と順序なら再現できます。v1〜v3とは乱数消費や規則が異なるため結果は一致しません。JSONの読み込み機能はありません。

## 構成

- `data.js`：90語の基本データと初期音韻体系
- `phonology.js`：16の環境依存規則、音素・異音、モーラ・音節、語形変異の分布
- `lexicon.js`：意味カテゴリ・概念関係、拡大・縮小・比喩・換喩・転用、多義化・旧義消失、複合語
- `grammar.js`：13動詞の実在する初期過去形と類推形、構文使用・文法化
- `cycles.js`：語ごとのコスト・識別性、意味関係による新語・補償、頻用・一語化・再縮約、年代別統計
- `grammar-cycles.js`：格・過去・否定・未来・完了・所有の標識、摩耗と補償、分析的／総合的な更新サイクル、例文
- `pressures.js`：圧力の計測・緩和・蓄積、競合する応答、連鎖の記録
- `simulation.js`：シード乱数、世代集団、接触網、移住、政策、借用・コードスイッチング、履歴
- `app.js`：画面操作、比較、履歴、記録保存
- `style.css`：レスポンシブ画面
- `tests/`：`npm test` で再現性、境界条件、規則の自然さ、画面のデータ接続を検証

## モデルの範囲

初期地域は同じ言語で社会条件が異なります。地域ごとに独立したシード乱数系列を使い、孤立地域の結果が他地域での乱数消費だけを理由に変わらないようにしています。新形の発生候補だけをシード乱数で選び、分節音の変更は環境に適合する規則だけで行います。規則ごとに発生しやすさ、速度、地域係数、前提規則を持ちます。弱化、母音間有声化、語頭無声化、条件的母音分裂と条件消失による音韻化、母音無声化、音節末鼻音の同化、流音異化、脱落・挿入、対立の環境別合流を実装しています。

語の基底列、表層変異、音韻的な列、モーラ、音節を分けて保持します。少なくとも1つの母音核を保持し、不適格な子音連続や長さの暴走を拒否します。小さな語彙表に偶然現れない音もあるため、音韻目録は初期宣言を保持し、条件別の合流は別に記録します。`I/U`は無声母音、`ŋ`は鼻音の条件異音です。これらを新音素とは数えません。`ö`は前舌化母音のゲーム内記号で、条件消失後に対立を持つ候補となります。ひらがなは読みの補助で、無声母音に小円、前舌化に二重点、鼻音異音に上付き記号を添えます。完全なIPA転写ではありません。

各地域に若年・成人・高年層があり、人口比、威信、二言語率と集団間ネットワークを持ちます。5年ごとに新形使用率が変化し、25年ごとに世代継承が進みます。65%は「定着」の表示基準で、全語を瞬間的に置換する閾値ではありません。低威信の変異は標準化によって消失し得ます。規則の普及率、語頻度、借用経路に応じて語形が共存します。計算量を抑えるため各語の主要8変異を保持・再正規化し、微小な変異は省略します。

地域接触は接続網×双方の交流率×双方の非孤立度で決まります。接触がゼロなら伝播、借用、標準形学習は起きません。接触期間、人口、威信、二言語話者が流入を左右します。借用形は地域の音韻体系に適応し、継承形と共存します。コードスイッチングは会話中の使用として別記録します。移住は接触先から話者を移し、若年人口比と二言語率に作用します。

類推では語幹＋i-ta型への一般化圧力と、頻度の高い継承形の保持を競合させます。「行く→いった」「来る→きた」等の初期活用を内部データで保持します。類推形はゲーム内で起こり得る革新形であり、現代日本語の正しい活用として提示していません。

文法化は「行く」の移動・予定構文、「しまう」の片付け・完了構文、「持つ」の所有関係節という3経路です。関連語の頻度と社会的な使用場面から累積使用量を計算し、語彙的用法→含意→文法的用法→融合・接辞化と段階的に進みます。文法画面に構文の実現例を表示します。特定の語が実際にこの接辞へ進化するという予測ではありません。主語助詞省略とSVOへの移行は別処理で、語順変化には持続した接触と二言語使用を必要とし、コードスイッチングを伴う会話の後置目的語構文の反復、または接触先の語順から証拠を蓄積します。目的語助詞を失う場合は役割を区別できる固定語順を維持します。

意味変化は内部の有向関係のみをたどります。例えば「頭→先端→（別の分岐で）指導者」「口→出入口」「道→手段」「家→家族」。新義と旧義の使用比率が変化し、条件によって旧義だけが失われます。語を無意味に削除する処理は廃止しました。複合語は構成要素と命名対象を対応させた内部テンプレートに限定します。v4では以下の循環モデルを通常の複合語形成に使用します。

類似度は基本90語の優勢表層形の正規化編集距離、多様性はその補数、相互理解度は音形類似度に文法差の減点を加えたゲーム内指標です。語彙変化率は音形または意味が変化した語の割合。文法変化率は3つの文法化経路の段階進行率です。意味が変わった語の同じ概念としての距離や、変異全分布の距離は指標に反映しません。系統図は共通起源と現在の音形差の模式図です。

## 短縮と補償の循環（v4）

**評価**：`word.functionalMetrics` は発音コスト（分節特徴の重み）、分節数・モーラ数、同音語・類似語、曖昧性、文法情報の欠落、識別性、経済性・識別性への圧力を保持します。`region.competition` は地域全体の二つの圧力、`grammar.functionalMetrics` は文法体系のコスト・情報損失・補償を表します。類似語は分節編集距離を使い、初期より近づいた組を新しい衝突として扱います。初期からの同音語数も統計には残しますが、すべてを強制的に解消はしません。

**補償的な語形**：新しい同音・近似衝突があった場合に、意味に適合する候補だけを比較します。場所＋物、身体部位＋機能、性質＋名詞、動作＋対象、上位分類＋下位概念という関係表を保持し、複合語、修飾語の固定、接頭・接尾要素、同義の新語、接続された他地域からの同一概念の借用を選びます。重みはアイデンティティ、教育、接触、既存語彙、過去の解決によって異なります。無関係なランダム音列は作りません。

**普及と再縮約**：`word.renewal` と `word.compound` に成立時の構成語、語形、使用量、普及率、一語化段階、縮約の規則、旧形を保持します。新形は少数の使用から始まり、旧形と共存します。反復使用が22に達すると結合が慣用化し、65で一語として再分析、95以上で経済性への応答として再縮約が可能になります。縮約は35年以上の間隔を空け、前の変異が普及してから次へ進みます。地域の音変化は新語にも適用します。

- `umi-ka → mika → mia`：場所名を添えて識別した後、弱い語頭母音、母音間子音が摩耗。
- `umi-sakana → umisana → misana → misa`：同母音を持つ弱い音節、語頭母音、弱い語末音節の縮約。

これらは**頻用・一語化した材料の条件付き規則**です。単なる経過年数だけで削除せず、適合する環境がなくなれば止まります。再縮約では少なくとも二つの母音核を維持し、語が消滅するのを防ぎます。新しい衝突が生じた場合は、別の補償サイクルに入れます。元の基本語だけでなく、文化・生業・意味分化の命名需要から「海魚」「湧き水」「手道具」「火打石」等の独立した語彙項目も生成し、語彙表・履歴・統計で観察できます。分類語が接辞になった場合は、語彙的接辞の種類数にも加えます。

**文法情報の補償**：`grammar.channels` が主格、目的格、過去、否定、未来、完了、所有という機能を保持します。標識は地域の音韻規則と、頻用する弱い文法的位置での融合・脱落を受けます。語彙の語全体は空になりませんが、宿主が残る文法標識はゼロ形になれます。標識が弱くなり機能の識別性が落ちると、次の補償が生まれます。

- 格：独立した名詞を新しい後置詞にする／語順を固定する／代名詞を併用して動詞一致へ進める。選択は教育・接触・地域アイデンティティ・既存の解決履歴に重み付けされ、地域名で強制しません。
- 過去：以前・終わる等の時間・完了表現を併用し、新しい時制標識にする。
- 否定：一つも・少しも・全く等を併用し、否定一致の慣用化を経て旧要素を失い、新形式に置き換える。二つの否定要素は**一つの否定の意味**を表し、肯定への反転はしません。
- 未来：行く由来の補助表現が接辞化・摩耗した後は、来る・思う・始める等の、関連した構文から新しい未来表現を作る。
- 完了・所有：すでに、終わる、ところ、人等の適合する材料によって更新する。

補償語の使用量20／55／95で、独立語→文法語→接語→接辞へと段階的に進みます。接辞化後は再び摩耗でき、補償フラグを解除して次の更新を可能にします。一部の固定語順による解決は安定して残ることもあり、全地域・全機能が同じ速度で一斉に回ることは要求しません。強調の「私＋自分」は反復によって自分由来の通常代名詞になり、代名詞由来の一致標識も動詞接辞になれます。例文はこの**現在の体系を実際に使って**生成します。

**履歴・統計**：イベントは `direction`（長文化・短縮・再分析等）、音素列の `before/after`、規則、理由、背景イベントIDを保存します。`region.languageHistory` には0年と5年ごとに以下を保存します。

| 値 | 定義 |
| --- | --- |
| 平均語長 | 基本語＋新語の優勢形の分節数の単純平均。モーラ平均も保存 |
| 平均文長 | 現在・過去・未来・否定・完了の共通5例文の分節数平均 |
| 形態素数 | 上記例文に含まれる明示的な構成要素の平均。慣用化・一語化や接辞の状態を反映した簡略解析 |
| 同音語数 | 異なる語彙項目の優勢形が同じになる組数。近似語の組数も保存 |
| 曖昧性 | 新しい語彙衝突と、補償後に残る文法情報の不明瞭さの合成指標（0〜1） |
| 接辞数 | 活動中の文法接辞と、語彙的な接頭・接尾要素の種類数 |

グラフは実際の記録値を使います。500年で必ず一定周期の波形になるような補正は入れていません。語が増えると平均語長の母集団も変わります。個別語の再縮約と辞書全体の増減は異なるため、履歴とグラフを併せて確認してください。

本モデルにはアクセント・詳細な実測の音響距離がないため、弱位置は形態的位置・頻用・一語化から近似します。日本語の全活用を生成する文法エンジンでもありません。補償による将来の新語・新標識は仮説的なゲーム内の形で、現代日本語の正しい語形や実際の将来予測とは区別してください。補助材料（自分、道具、以前、すでに等）は内部の小さな語彙表で保持し、実行時の外部辞書・APIは使いません。

開発用に `{cycles:false}` で循環のみ、`{pressures:false}` で圧力フィードバックと循環を無効化できます。通常の介入なし世界も循環は有効です。モデルバージョンと有効フラグはJSON出力に含みます。

## 内的圧力と連鎖（v3から維持した基盤）

各地域の `pressures` は0〜1、画面では0〜100で表示します。5年ごとに現状から目標値を計算し、現在値を目標へ28%ずつ近づけます。接触の経路がゼロになったときの接触圧は直ちにゼロになります。圧力の履歴は `pressureHistory`、観測根拠は `pressureEvidence`、応答の蓄積と待機期間は `pressureState` に保持します。

| 圧力 | 主な発生源 | 主な作用・反作用 |
| --- | --- | --- |
| 発音省力化 | 使用頻度で重み付けした分節数、交流・若年話者の発話負荷 | 適用可能な弱化・短化規則の発生と普及、反復構文の縮約。語形が短くなると低下 |
| 明瞭性維持 | 初期にはなかった同音衝突、語形の揺れ、短縮、曖昧性 | 分類語を添える区別化複合、過剰な弱化の抑制。区別が回復すると低下 |
| 文法的曖昧性 | 助詞省略、多義化、活用と構文の共存 | 語順・目的語標識の再固定、類推による平準化。固定後は負荷が低下 |
| 標準化 | 教育、地域の威信、語形変異の多さ、標準語政策 | 地域独自の革新・省略を抑制。実際に接続された中央語との学習を支える |
| 接触 | 実在する接続網、交流率、接触期間、二言語率、地域間の音形差 | 借用・特徴伝播と構文使用に作用。未接続地域からの伝播は発生させない |

圧力は互いに競合します。省力化の応答は圧力の蓄積が8に達し、前回から30年以上経過し、明瞭性圧力が0.65未満の場合だけ生じます。適用環境がある規則を選び、既存の発生抽選率は引き上げていません。規則は従来どおり世代内で普及し、支持が低ければ消失します。

代表的な連鎖：

- `母音間h脱落 → 長母音短化 → 母・葉の同音化 → 明瞭性圧力 → 葉＋木という区別化複合 → 衝突の解消 → 明瞭性圧力の低下`
- `区別化複合で語が長くなる → 発音負荷が増す → 次の省力化への圧力`
- `構文の反復 → 文法化 → 行く／予定される等の新義 → 意味的支持を得た構文の反復・文法化`
- `構文の多義性・助詞省略 → 曖昧性の蓄積 → 固定語順・標識の保持 → 曖昧性の低下`

区別化複合は新しい同音衝突だけを対象にし、元からある「火・日」等の同音語は強制的に解消しません。旧形と新形は共存し、導入直後に即時置換しません。同じ衝突の修復が普及中なら、すぐに別の語にも分類語を重ねません。分類語は既存の内部語彙から選びます。

各イベントの `causes` は前のイベントIDを参照します。圧力応答の背景となった変化、誘発された音韻規則、優勢語形交代、意味拡張を追えます。圧力は地域の複数の観測値を合成したゲーム内指標であり、背景イベント一覧は厳密な反実仮想による因果推定ではありません。画面の「変化が、次の変化を呼ぶ。」で地域別の値・直前の評価からの差・連鎖を確認できます。「介入なしと比較」には両世界の圧力も表示します。

開発用に `new Drift.Simulation(seed, {pressures:false})` で圧力から変化へのフィードバックを無効化できます（計測は継続）。これは現在のモデル内の対照実験であり、v2の完全な再現ではありません。通常の「介入なし」世界では圧力モデルは有効です。保存JSONにも有効フラグを記録します。

## 研究との対応と限界

以下を参考に、変化を扱う仕組みを設計しています。各係数、閾値、候補経路はゲームのための仮定で、研究データに適合させた予測モデルではありません。アクセント、全活用体系、個々人の発話、実測コーパスはモデル化していません。構文使用量は内部生成した期待使用量であり、実際の会話コーパスの件数ではありません。

- [Bybee, From usage to grammar (2006)](https://www.unm.edu/~jbybee/downloads/Bybee2006FromUsage.pdf)：頻用する構文の慣用化と縮約を結びつける設計。
- [Negation in Early English, Introduction](https://www.cambridge.org/core/books/abs/negation-in-early-english/introduction/5DE4128022AEBAE4ABC4B57F87F90723)：否定の補強と旧要素消失の循環を参考にした設計。弱化が必ず補強の原因になるという経験的主張ではありません。
- [Labov, Transmission and diffusion (2007)](https://www.cambridge.org/core/journals/language/article/abs/transmission-and-diffusion/19AAEFAAE6023EBF6634AA483B1A856E)：地域内の世代継承と地域間の拡散を区別する設計。
- [Bybee, Diachronic Linguistics (2007)](https://www.unm.edu/~jbybee/downloads/Bybee2007DiachronicLinguistics.pdf)：頻度・類推・継承形の保持を分ける設計。
- [Bybee, Mechanisms of Change in Grammaticization: The Role of Frequency](https://onlinelibrary.wiley.com/doi/10.1002/9781405166201.ch19)：反復使用、音形縮約、意味・文法機能の変化を連動させる設計。
